## 打开方式

- 直接双击上述文件，或浏览器打开 `file://<仓库根>/dashboard/...`。
- 纯静态页面，无外部依赖、无网络请求，可离线查看。

## 时间与同步约定（当前有效规则）

1. **Git 同步仅在用户明确说「同步」后执行**，无变更不制造空提交。本目录页面由 Codex 提出阶段任务后制作，并随该次同步更新——**不代表自动同步**。
2. 页面顶部的「本页生成时间」是固定值，不是打开时的当前时间；「数据快照时间」单独列出。
3. 权威来源是 `任务与验收台账.md`（该文件**仅本地可用**）。

## 范围约定（公开 vs 仅本地）

- 本目录下的页面属于**公开文件**，会随 Git 同步到 GitHub。
- 页面内带 **「仅本地」** 标记的链接，指向已被 `.gitignore` 排除的文件（`research/`、`交付报告/`、`审查/`、`AGENTS.md`、`任务与验收台账.md`、`tests/**/logs/`、`设计/` 中的协作任务卡等）。这些文件**不在公开仓库中**，此类链接仅在本地打开时有效。
- **`设计/` 目录逐项区分**：当前 2 个文件（INT-001、VIS-002 任务卡）均为协作任务卡，留本地；后续产品设计文档默认同步，新增时逐项确认。
- 页面内只有**已核对存在的路径**会渲染为链接（白名单机制），`origin/main` 等普通引用一律显示为纯文本，避免死链。

## 统计口径

- 所有计数由任务状态直接计算，与任务卡明细一致；KPI 覆盖全部状态（**含「需返工」**）。
- 验收分三个维度分别展示：**文档 / 构建 / 实机**。实机未测不折算为完成比例。
- **不显示虚构完成百分比**。「已验收」仅在任务状态 = 已验收时计入。

- 台账或产物变化 → HY 更新页面内嵌数据 → 用户说「同步」后提交推送并核对远程 `main` 与本地 `HEAD` 一致。
- 新增产物在任务卡「产物 / 证据」中补相对链接（`../` 前缀，相对仓库根）。

页面内产物 / 证据链接使用相对路径前缀 `../`，指向仓库根目录下的对应文件；命中「仅本地」规则的路径会自动附加标记。
