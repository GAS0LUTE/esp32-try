## 重要约定（按 AGENTS.md / 大纲第七节）

1. **本页是静态快照，不是自动同步的承诺。** 内容由 HY 按台账手工内嵌，每次台账或产物更新后由 HY 重新生成此页并随 Git 提交。权威来源始终是 `任务与验收台账.md`。
2. **不虚构进度、不用无依据完成百分比。** 页面顶部的「已验收」数值严格按任务状态 = 已验收 计数，并在标签下注明口径；其余任务只标真实状态（待领取/进行中/待审查/阻塞/暂停/待明确）。
3. **HY 不写固件、不做设计决策。** 看板只展示进度与产物入口，不替代 Codex 的审查与汇报。
4. 任务状态仅有：待明确、待领取、进行中、待审查、需返工、阻塞、已验收、暂停。HY 只能把 **Codex 明确通过**的任务改为「已验收」。

## 更新流程

- 台账变化 → HY 改 `任务与验收台账.md` → 同步更新本页 `DATA` 对象中的对应条目 → 提交并推送。
- 新增产物（如 `research/`、`交付报告/`）→ 在任务卡的「产物/证据」中补相对链接（`../` 前缀，相对仓库根）。
- 每轮收口由 HY 串行 `git commit` + `git push`，核验远程 `main` 与本地 `HEAD` 一致。

## 链接约定

页面内产物/证据链接均使用相对路径前缀 `../`，指向仓库根目录下的对应文件（如 `../research/案例对比.md`）。
